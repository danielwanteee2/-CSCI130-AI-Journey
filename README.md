# CSCI 130: AI Journey

My journey learning about AI at NDSCS.

## Start here

You need Python 3 installed. Open this folder in VS Code, then run the script in a terminal:

```powershell
python hello_ai.py
```

If `python` is not recognized on Windows, try:

```powershell
py hello_ai.py
```

The program asks for your name and prints a short introduction. It is a Python exercise, not an AI model, and it needs no extra packages.

## First experiment

Open `hello_ai.py`, change one of the printed messages, and run it again. Then try leaving the name blank and notice how the program responds.

## Learning notes

For each new idea, record:

- **Concept:** What did I learn?
- **Example:** Where might I see it in everyday life?
- **Question:** What am I still unsure about?
- **Test:** What small experiment could help answer my question?

## Suggested path

1. Practice Python basics: values, input, conditions, loops, and functions.
2. Learn AI vocabulary: data, examples, patterns, predictions, and evaluation.
3. Try a small supervised-learning example and compare its predictions with known answers.
4. Check where its data came from, what it misses, and when its predictions should not be trusted.
